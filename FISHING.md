# Рыбалка

Этот файл предназначен для отдельного проектирования механики рыбалки перед изменением рабочего кода.

## Цель

Добавить отдельный маршрут рыбалки, не затрагивая существующие рабочие модули:

- обычный фарм;
- события;
- бои;
- стамину;
- починку;
- Арену;
- Гильдейский зачёт;
- команды в «Избранном»;
- работу двух Telegram-аккаунтов.

## Статус

Пока создан только документ для описания логики.

Код рыбалки ещё не добавлен и ни один рабочий файл не изменён.

app/routes/fishing.py

## Что нужно определить перед реализацией

### 1. Как открыть рыбалку

Нужно записать точный маршрут по кнопкам, например:

```text
Главное меню
→ ...
→ Рыбалка
```

### 2. Как начать ловлю

Нужно указать точный текст кнопки запуска рыбалки.

### 3. Какие сообщения и кнопки появляются во время ловли

Для каждого состояния нужно сохранить:

- текст сообщения игры;
- доступные кнопки;
- какую кнопку необходимо нажать;
- что происходит после нажатия.

### 4. Условия завершения

Нужно определить:

- количество попыток;
- ограничение по времени;
- окончание наживки;
- заполнение инвентаря;
- отсутствие энергии или другого ресурса;
- ручное завершение маршрута.

### 5. Приоритет рыбалки

Нужно решить, когда рыбалка может запускаться:

- отдельным режимом;
- вместе с обычным фармом;
- только по команде;
- по расписанию;
- после Арены и Гильдейского зачёта.

### 6. Поведение во время боя

Перед запуском рыбалки необходимо решить:

- завершать ли активный бой;
- ждать ли окончания босса;
- можно ли прерывать обычное исследование;
- как возвращаться после рыбалки.

### 7. Возврат после рыбалки

Нужно описать точный маршрут возврата:

```text
Рыбалка завершена
→ Главное меню
→ Исследовать
→ выбранный этаж
→ последняя локация
→ Продолжить исследование
```

## Безопасный план реализации

1. Записать в этом файле полный маршрут по скриншотам.
2. Создать `app/routes/fishing.py` без подключения к рабочему запуску.
3. Добавить распознавание всех состояний рыбалки.
4. Подключить отдельный тестовый режим.
5. Проверить маршрут на одном аккаунте.
6. Только после проверки включить его для второго аккаунта.
7. Не менять существующие маршруты без отдельной необходимости.

## Материалы для заполнения

Для реализации нужны скриншоты или точные тексты каждого шага:

1. кнопка входа в рыбалку;
2. экран выбора места или удочки;
3. кнопка начала ловли;
4. момент поклёвки;
5. успешный улов;
6. неудачная попытка;
7. отсутствие наживки или ресурса;
8. экран завершения;
9. кнопка возврата.
